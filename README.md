# MusicSense AI - Stable 205

- **Local Windows:** Whisper + Argos Translate, Python backend; sem API paga.
- **Netlify:** interface publica demonstrativa; nao possui backend de IA. A transcricao/traducao exige um servidor Python dedicado e seguro.
- **Arquivos de instalacao:** PREPARAR_FERRAMENTAS_WINDOWS.bat, INSTALAR_WINDOWS.bat, INICIAR_WINDOWS.bat, ATUALIZAR_WINDOWS.bat.
- **Pacote ZIP:** criado separadamente na pasta local do Alien_Ware, nao inclui modelos nem ambientes virtuais.

## Privacidade
Nunca publicar cache, audios pessoais, modelos ou credenciais. O servidor local escuta apenas 127.0.0.1 e nao deve ser exposto diretamente.
